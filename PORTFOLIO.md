# Upwork portfolio entry: Luma Hair Studio

Copy these into **Profile → Portfolio → Add a project** on upwork.com.

## Project title

Salon booking app with live availability & staff dashboard (React)

## Your role

Designer and front-end developer

## Project description

An online booking system for a hair salon (a fictional business, built as a portfolio piece).

- Real availability from stylist schedules, opening hours, breaks and service length
- "First available stylist" option that spreads work evenly across the team
- Customers can book, reschedule, cancel and add appointments to their calendar
- Staff dashboard: day schedule per stylist, revenue, no-shows and trends
- React + TypeScript, 29 automated tests, light and dark mode, mobile-first

## Skills (pick up to 5)

React · TypeScript · Web Application · Front-End Development · Responsive Design
